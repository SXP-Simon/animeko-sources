# helian

Animeko 在线源订阅。

在 Ani 的数据源订阅设置中添加：

```text
https://raw.githubusercontent.com/SXP-Simon/animeko-sources/main/helian.json
```

包含 girigiri、秋之动漫、稀饭动漫 Next 和 AGE动漫。AGE 可能需要手动完成人机验证，暂未验证播放。

规则参考 [Ani 内置订阅](https://sub.creamycake.org/v1/css1.json)、[MajoSissi/animeko-source](https://github.com/MajoSissi/animeko-source) 和 [Predidit/KazumiRules](https://github.com/Predidit/KazumiRules)。
